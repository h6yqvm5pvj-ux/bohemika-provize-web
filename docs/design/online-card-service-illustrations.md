# Online card service illustrations

Generated with the built-in imagegen tool for the eight service cards in `AdvisorProfileSections`. Each subject was generated separately using the shared art direction below. Final web assets live in `public/images/online-card-services/` as WebP files with transparency preserved.

The illustrations are decorative: the localized service name and description remain real text in the card.

Output: square PNG, ideally 1024 by 1024 pixels, transparent alpha.
