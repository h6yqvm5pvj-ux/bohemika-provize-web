# Podklad pro dohledání zprávy u poskytovatele pošty

Návrh textu; nikam nebyl odeslán. Příjemce doplní vlastník schránky při autorizovaném požadavku na podporu.

> Dobrý den, prosím o dohledání nedoručeného e-mailu pro obnovení hesla.
>
> Příjemce: moje testovací schránka, kterou doplním do tohoto požadavku.
>
> Odesílatel používá výchozí doručování Firebase Authentication z projektové domény `firebaseapp.com`. Přesnou adresu odesílatele doplním z Firebase Authentication → Templates → Password reset → From.
>
> Čas žádosti: 13. 9. 2026, 10:24 CEST (08:24 UTC). Prosím zkontrolovat i následující desítky minut kvůli možnému zpoždění fronty.
>
> Firebase přijal právě jednu žádost s HTTP 200. Zpráva není ve webmailu ani ve složce Spam. Prosím potvrdit, zda se odesílající server pokusil zprávu doručit, a případně uvést důvod odmítnutí, SMTP stav a použitou antispamovou politiku. Nepotřebuji obsah zprávy ani odkaz pro změnu hesla.

Pokud poskytovatel nenajde ani pokus o přijetí, další šetření patří podpoře Firebase. HTTP 200 samo o sobě není dokladem pokusu o SMTP doručení.
